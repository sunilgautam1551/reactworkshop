# React, Deeply ⚛️

### Advanced React Workshop for Senior Engineers

An interactive, hands-on React workshop focused on understanding **how React works under the hood**, rather than only learning API usage.

🌐 **Live:** https://reactworkshop-pi.vercel.app/

---

## 🎯 What This Covers

A structured collection of advanced React concepts covering:

* React rendering & reconciliation
* Fiber architecture
* Hooks & state management
* `useMemo`, `useCallback`, and `useRef`
* Context and component composition
* Effects and lifecycle behavior
* React Router
* Performance optimization
* Memoization & rendering behavior
* Server Components
* Next.js concepts
* Concurrent rendering
* React 19 features
* Practical React patterns
* Common interview scenarios

---

## 🧠 Approach

The workshop focuses on understanding the **why and how behind React**, including:

* What happens during rendering
* How React tracks state
* How Fiber enables modern rendering
* Why components re-render
* How dependency arrays are compared
* When memoization helps or hurts
* How React handles asynchronous updates
* How to reason about performance problems

The goal is to build **mental models**, not memorize APIs.
